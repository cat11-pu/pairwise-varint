# varint

一个只依赖 Python 标准库的变长整数编解码内核。它不监听端口、不读写文件，
只在内存里把整数编成字节、把字节解回整数：7 位分组加续位、zigzag 有符号
映射、两种分组顺序（低位组在前、高位组在前）、多值缓冲解码与可增量的流式读取。

- 无符号整数：7 位一组的 varint，最短写法，最长 10 字节，最大 64 位
- 有符号整数：zigzag 映射后再按无符号写法编码
- 大端分组：最高位组在前的同族写法，供包偏移一类只需正数的场景使用
- 错误情形：截断、超过 10 字节、超出 64 位、非最短写法
- 解析方式：整缓冲区多值解码、可增量的流式读取器

## 目录

- varint/core.py：编解码与读取器
- tests/test_core.py：行为测试

## 跑测试

在项目根目录执行：

    python3 -m unittest discover -s tests -v
